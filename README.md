# «Remex_v3»
Програмна модель «Remex_v3» розроблена для прогнозування динаміки нафтозабруднення та біоремедіації ґрунтів України з урахуванням географічних і природно-кліматичних факторів. За результатами верифікації точність прогнозування моделі становила 96,77 %. The software model «Remex_v3» was developed to predict the dynamics of oil contamination and soil recovery in Ukraine, considering geographical and climatic factors. The validation results demonstrated that the model achieved a prediction accuracy of 96.77%.
