# «Olimpia_v4»
Програмна модель «Olimpia_v4» розроблена для прогнозування динаміки нафтозабруднення та відновлення ґрунтів України з урахуванням географічних і природно-кліматичних факторів. Її точність підтверджено шляхом верифікації на основі порівняння результатів моделювання з реальним випадком нафтозабруднення в м. Харків, спричиненим руйнуванням нафтосховища внаслідок удару безпілотного літального апарата (БпЛА).
