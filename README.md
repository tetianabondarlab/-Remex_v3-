# «Olimpia_v4»
Програмна модель «Olimpia_v4» розроблена для прогнозування динаміки нафтозабруднення та відновлення ґрунтів України з урахуванням географічних і природно-кліматичних факторів. За результатами верифікації точність прогнозування моделі становила 96,2 %. The software model «Olimpia_v4» was developed to predict the dynamics of oil contamination and soil recovery in Ukraine, considering geographical and climatic factors. The validation results demonstrated that the model achieved a prediction accuracy of 96.2%.
